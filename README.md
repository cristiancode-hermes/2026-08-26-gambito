# Gambito

Café de juegos de mesa B2C: el visitante ve mesas libres, arma una mochila con **copias físicas reales**, retiene 15 min y confirma con **pase QR** (`/partida/:code`).

- Frontend: Angular 22 (signals, zoneless)
- API: NestJS 11 + TypeORM + SQLite (Neon-ready)
- Puerto API: **3075**
- Demo: `gambito` / `demo@gambito.dev` / `demo1234`

La caja no se inventa. Se cuenta.
